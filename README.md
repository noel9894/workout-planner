# workout-planner

Personal workout planner with a mobile-first interface.

## Run locally

```bash
python3 -m http.server 4173
```

Then open: `http://localhost:4173`.

## GitHub Pages URL

A Pages workflow is included in `.github/workflows/deploy-pages.yml`.
After pushing this branch to your GitHub repository and enabling Pages (GitHub Actions source), the app URL will be:

`https://<your-github-username>.github.io/workout-planner/`
